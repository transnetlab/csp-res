# csp-res
Codes for a charge scheduling problem (CSP) with renewable energy sources (RES)

Run the csp_pipeline.py file after installing the modules using requirements.txt. Enter the run_ids corresponding to the Durham_2.1k network. Run IDs can be found in the generating_run_file.py file. 

Pickle files for the input data have been compressed using lzma. Please uncompress before running the codes. 

Run visualization_main.py file inside the visualization_updated folder to generate the plots used in the paper.
